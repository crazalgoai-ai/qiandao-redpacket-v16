# 千岛湖淳鱼红包活动原型 V16

当前最新的静态交互原型，可发布到 GitHub Pages，无需安装依赖或构建。

## 上传与发布

1. 解压 ZIP，将里面的 `index.html`、`assets` 文件夹、`README.md`、`.nojekyll`、`.gitignore` 上传到 GitHub 仓库根目录，保持文件夹结构。不要只上传 ZIP。
2. 打开仓库 **Settings → Pages**，选择从分支发布；选择上传文件所在分支（通常为 `main`），发布目录选择 **/(root)**，保存。
3. 部署完成后，打开 Pages 页面提供的网站链接。

如果文件选择器隐藏点号开头的文件，可在仓库中补建空白 `.nojekyll` 文件。仓库根目录应直接看到 `index.html`，不要再套一层外部文件夹。

## 最新交互

- 扫码先看溯源报告，主动点击红包才进入转盘。
- 当前码绑定有效活动且仍有可用抽奖机会时显示红包，抽完后隐藏。
- “我的奖品”位于问题反馈下方；未识别用户时不显示角标，获取用户信息后按本账号待领取奖励显示数字角标。
- 用户信息授权、位置授权按顺序校验；查看奖品不申请位置。
- 每笔红包必须在微信确认收款后才完成领取，不包含免确认收款授权流程。
- 取消收款保留奖励；异常领取归并为待领取记录，可继续领取原奖品，不重新抽奖。
- 弹窗底部不展示“待领取”标签；不再单独弹出活动结束提示，结束后仍可访问我的奖品。

左侧为演示控制和分类页面预览，右侧为消费者界面。数据与微信页面均为演示，未连接真实微信或营销 SaaS，不实际授权、定位、抽奖或转账。刷新页面会重置演示数据。

## 文件

```text
index.html               页面入口
assets/styles.css        样式
assets/app.js            交互和演示数据
assets/brand-report.png  项目提供的品牌素材
README.md                说明
.nojekyll                静态发布配置
.gitignore               本地文件忽略配置
```

资源使用相对路径，支持 GitHub Pages 仓库子路径。本包只包含当前原型，不包含旧版本、PDF 或 UE 图板。
